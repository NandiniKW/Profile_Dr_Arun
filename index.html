Ph.D. research project

CBMIR: Content-Based Multimedia Information Retrieval

An open-source search engine for educational lecture archives. Doctoral work at Visvesvaraya Technological University, with K. R. Mulla.

Problem. Lecture videos on YouTube and MOOC platforms are found only through titles, tags and manual annotations. Students lose time browsing videos to find one topic. Commercial tools that index video content are costly for institutions, and open-source repository systems handle only documents and images.

Solution. CBMIR lets an institution build a subject-wise lecture archive and search the full spoken content of every video. A search result starts playing at the moment the keyword is spoken.

Upload video or link›Video to audio (FFmpeg)›Speech to text (PocketSphinx)›Time-segmented transcript›Full-text index (Whoosh)

Three modules

  • Administrator: uploads videos, manages the library, edits transcripts and assigns limited admin roles.
  • Processing and retrieval: converts, transcribes, segments and indexes each video automatically.
  • User: a search box with topic-wise collections; results jump to the matching timestamp.

Features

  • Open source, built on Django, Python and Whoosh on Ubuntu
  • Fast full-text search with time-segmented playback
  • No video advertisements; lightweight storage and no upload limit
  • Subject-based repositories for universities, R&D and non-profit bodies in India

Next steps

Currently English speech only. Planned: Indian regional-language transcription and translation, voice search, OCR of slides, object detection in video and a user dashboard. Source code is planned for GitHub under a CC BY-NC licence after the degree.
